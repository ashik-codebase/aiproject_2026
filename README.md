# Sample HTML Project

## 📖 Overview
This project demonstrates a basic HTML page structure. It includes:
- A main heading
- A paragraph of text
- An unordered list
- A clickable hyperlink

The goal is to provide a starting point for learning and experimenting with HTML.

---

## 🚀 Getting Started
1. Save the provided HTML code into a file named `index.html`.
2. Open the file in any modern web browser (Chrome, Firefox, Edge, Safari).
3. You’ll see a simple webpage with headings, text, and a link
